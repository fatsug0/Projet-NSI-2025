## 🎬 Synopsis

L’humanité a sombré dans le chaos après la propagation d’un virus inconnu (**COVID-20**), transformant la majorité de la population en créatures affamées de chair humaine.

La ville est devenue une **zone morte**, abandonnée par l’armée et livrée aux hordes de zombies.

Vous incarnez **Alex Carter**, un ancien soldat piégé dans cette cité en ruines.  
Votre objectif : **survivre le plus longtemps possible** et tenter de trouver un moyen de vous échapper avant d’être submergé.


## 🕹️ Objectif

- 🧭 Trouvez des **ressources**, des **armes** et des **points d’évacuation**.
- 🧠 Gérez votre **inventaire** stratégiquement.
- ⚠️ Plus vous restez en ville, **plus les zombies deviennent rapides et nombreux**.
- 🚁 Une rumeur parle d’un **hélicoptère** venant extraire les survivants... **Tiendrez-vous jusque-là ?**


## 🎮 Contrôles

| Action                | Touche par défaut |
|-----------------------|-------------------|
| Se déplacer           | `Z Q S D`         |
| Courir                | `Shift Gauche`    |
| Tirer                 | `Espace`          |
| Recharger             | `R`               |
| Ramasser un objet     | `E`               |
| Poser un objet        | `G`               |
| Ouvrir l'inventaire   | `I`               |
| Changer d'arme        | `1 - 5`           |

## 🔧 Installation

#### Si vous avez l'engin Unity
1. **Cloner** ce dépôt
2. Ouvrir le projet avec **Unity Hub** (version 6000.0.44f1 ou +)
3. Lancer la scène `MainScene.unity`
4. Appuyer sur ▶️ pour jouer


#### Sinon vous n'avez pas l'engin Unity
1. Ouvrir l'onglet **Releases**
2. Récupérer la dernière vesion du jeu (si elle existe)
3. Télécharger et lancer le jeu
